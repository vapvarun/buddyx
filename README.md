# BuddyX

A free WordPress theme for BuddyPress, LearnDash, LifterLMS, LearnPress, TutorLMS, and the BuddyBoss Platform. BuddyX ships a typography-led design system, 27 block patterns, a self-contained Customizer framework, design tokens, and native dark mode.

> Full theme details, requirements, and changelog live in [`readme.txt`](readme.txt) (the WordPress.org-formatted readme).

## Try BuddyX in your browser

[![Try in WordPress Playground](https://img.shields.io/badge/Try%20in-WordPress%20Playground-1E40AF?logo=wordpress&logoColor=white)](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/vapvarun/buddyx/master/_playground/blueprint.json)

Launches a disposable WordPress site in your browser with:

- The latest WordPress.org release of **BuddyX** installed and activated
- **BuddyPress** active so community features (members, groups, activity) are live
- The theme's built-in **sample content** published automatically - 7 pattern-driven pages (Home, About, Services, Pricing, Journal, FAQ, Contact), a primary navigation menu, and a static front page

Nothing is installed on your machine and the site is discarded when you close the tab.

> The Playground demo pulls BuddyX from the WordPress.org theme directory, so it always reflects the current approved release. Sample content is created by the theme's own [`Starter_Content`](inc/Starter_Content/Component.php) component, which requires BuddyX 5.1.0 or later.

### Blueprint

The Playground setup lives in [`_playground/blueprint.json`](_playground/blueprint.json). To run it locally:

```bash
npx @wp-playground/cli@latest run-blueprint --blueprint=_playground/blueprint.json
```
